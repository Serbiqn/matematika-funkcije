1

Funkcija je mašina, tačka je adresa

Zamisli automat za sokove. Ubaciš novčić, automat nešto uradi i izbaci sok. Funkcija radi isto: ubaciš broj x, ona izbaci broj y. f(x) = 2x − 4 znači: "uzmi broj, pomnoži ga sa 2, pa oduzmi 4".

Kad piše f(3), to je naredba: svuda umesto x napiši 3.

Na testu napišif(3) = 2 · 3 − 4 = 6 − 4 = 2

Svaki par (ulaz, izlaz) je jedna tačka na grafiku: (3, 2). Prvi broj je uvek x, drugi y. Kako je nađeš? Kao u zgradi: prvo prošetaš hodnikom 3 koraka desno (to je x), pa se liftom popneš 2 sprata (to je y). Negativan x znači hodaš levo, negativan y znači silaziš u podrum.

Nula funkcije

N(x, 0). Mesto gde grafik seče x-osu. Tu je y = 0.

Presek sa y-osom

(0, f(0)). Ubaciš x = 0.

Teme parabole

T(xT, yT). Najniža ili najviša tačka parabole.

Probaj: pomeraj klizač
2

Domen: šta sme u mašinu

Domen su svi brojevi koje smeš da ubaciš umesto x, a da se mašina ne pokvari. U ovom gradivu mašinu kvari samo jedna stvar: deljenje nulom. Ne postoji broj koji je 5 : 0, zato je to zabranjeno.

Nema x u imeniocu (polinom)

2x − 4, x2 − 2x − 3, x3 − 4x: sme svaki broj.

D = ℝ, odnosno x ∈ (−∞, +∞).

Ima x u imeniocu (razlomak)

2x − 4x + 1: imenilac ne sme biti 0.

x + 1 ≠ 0 ⇒ x ≠ −1

Na testu napišix + 1 ≠ 0 ⇒ x ≠ −1D = ℝ \ {−1} = (−∞, −1) ∪ (−1, +∞)
Probaj: ubaci bilo koji broj

isprekidana linija: x = −1, tu grafik "puca" jer je imenilac 0

Za svaki slučaj: postoji još jedna zabrana, ispod korena ne sme negativan broj. Na ovom testu nema korena, ali dobro je znati.

3

Nule: gde grafik seče x-osu

Nula funkcije je x za koji je f(x) = 0. Recept je uvek isti: napiši f(x) = 0 i reši jednačinu. Razlikuje se samo kako je rešavaš.

Linearna

2x − 4 = 0

2x = 4

x = 2 ⇒ N(2, 0)

Razlomak

Razlomak je 0 samo kad je brojilac 0.

2x − 4 = 0 ⇒ x = 2

Proveri da 2 nije zabranjen broj iz domena (nije, zabranjen je −1).

Kubna: izvuci x

x3 − 4x = 0

x(x2 − 4) = 0

x(x − 2)(x + 2) = 0

Proizvod je 0 kad je bar jedan činilac 0: x = 0, x = 2, x = −2.

Kvadratna: formula

x2 − 2x − 3 = 0

a = 1, b = −2, c = −3

D = b2 − 4ac = 4 + 12 = 16

x1,2 = 2 ± 42 ⇒ x1 = 3, x2 = −1

Ovde se najčešće greši

Pazi na minus: 2 − 42 = −22 = −1, a ne 1. Uvek proveri: ubaci rezultat nazad. f(−1) = 1 + 2 − 3 = 0, znači tačno.

Korisne formule

Razlika kvadrata: a2 − b2 = (a − b)(a + b), npr. x2 − 4 = (x − 2)(x + 2).

Brzi trik za kvadratnu sa a = 1: traži dva broja čiji je proizvod c, a zbir b. Za −3 i −2 to su −3 i 1, pa x2 − 2x − 3 = (x − 3)(x + 1). Nule su sa obrnutim znakom: 3 i −1.

4

Znak: iznad ili ispod ose

Znak funkcije pita: gde je grafik iznad x-ose (f(x) > 0, pozitivna) a gde ispod (f(x) < 0, negativna)?

Nule (i zabranjeni brojevi iz domena) seku osu na komade, intervale. Na jednom komadu znak se ne menja. Menja se samo kad prođeš kroz nulu.

Metod A: proba broja

Iz svakog intervala uzmi bilo koji broj i ubaci ga. Za 2x − 4x + 1, granice su −1 i 2:

x = −2: −8−1 = 8 → +

x = 0: −41 = −4 → −

x = 3: 24 > 0 → +

Metod B: tablica (kao u svesci)

Svaki deo posebno, pa pomnožiš znakove. Minus puta minus je plus.

Na testu napišif(x) > 0 za x ∈ (−∞, −1) ∪ (2, +∞)f(x) < 0 za x ∈ (−1, 2)
Trik za parabolu

Ako je a > 0, parabola je "osmeh": pozitivna van nula, negativna između nula. Ako je a < 0, obrnuto.

Probaj: zeleno je iznad ose, crveno ispod

6

Parna i neparna: test ogledala

Recept u 3 koraka: 1) svuda umesto x napiši (−x), 2) sredi, 3) uporedi sa početnom funkcijom.

Parna

Dobiješ isto: f(−x) = f(x).

Grafik je simetričan u odnosu na y-osu. Kao leptir.

Primeri: x2, x2 − 4

Neparna

Dobiješ sve znakove obrnuto: f(−x) = −f(x).

Grafik je simetričan u odnosu na koordinatni početak (0, 0). Okreneš za 180°, isto je.

Primeri: x3, x3 − 4x

Ni jedno

Nije ni isto, ni sve obrnuto.

Nema ni jednu od ove dve simetrije.

Primeri: 2x − 4, x2 − 2x − 3

Pravila za minus

(−x)2 = x2 (paran stepen pojede minus) · (−x)3 = −x3 (neparan ga zadrži) · −2 · (−x) = +2x · broj bez x, npr. −3, ostaje isti.

−f(x) znači: promeni znak svakom članu, i broju na kraju.

Primer kako se piše (4. zadatak) f(−x) = (−x)2 − 2(−x) − 3 = x2 + 2x − 3 −f(x) = −x2 + 2x + 3 f(−x) ≠ f(x) i f(−x) ≠ −f(x) ⇒ funkcija nije ni parna ni neparna.
Brza provera u glavi

Gledaj stepene. Samo parni stepeni i broj (x4, x2, 5): parna. Samo neparni stepeni bez broja (x3, x): neparna. Mešano: ni jedno. Na testu ipak napiši ceo postupak sa f(−x).

Probaj: ogledalo uživo

A(a, f(a))B(−a, f(−a))

Kvadratna funkcija od A do Š

Oblik: f(x) = ax2 + bx + c. Grafik je parabola. Prvo prepiši a, b, c sa znakovima: kod x2 − 2x − 3 je a = 1, b = −2, c = −3.

Smer

a > 0: otvorena nagore, kao osmeh. Teme je minimum.

a < 0: otvorena nadole, tužan smajli. Teme je maksimum.

Diskriminanta

D = b2 − 4ac

D > 0: dve nule · D = 0: jedna · D < 0: nema nula.

Nule

x1,2 = −b ± √D2a

Teme i ekstrem

xT = −b2a,   yT = f(xT)

Ekstremna vrednost je yT. Presek sa y-osom je (0, c).

Kalkulator: upiši bilo koju kvadratnu i vidi ceo postupak
